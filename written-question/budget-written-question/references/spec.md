# 입력 JSON 규격 (spec.json)

예시: [../examples/sample_spec.json](../examples/sample_spec.json)

## 머리 정보 (모두 필수)

| 키 | 뜻 | 예 |
| --- | --- | --- |
| `ministry` | 대상부처. **1개만** | `과학기술정보통신부` |
| `committee` | 소관 상임위 | `과학기술정보방송통신위원회` |
| `member` | 의원 이름 | `홍길동` |
| `party` | 정당 | `가나다당` |
| `session` | 회차(뒤에 "예산결산특별위원회"는 자동) | `제439회국회(정기회) 제5차` |
| `date` | 제출일 (신청서·목록 공통) | `2026년 11월 9일` |

## items — 예산 질의 (감액·증액)

| 키 | 필수 | 뜻 |
| --- | --- | --- |
| `section` | ○ | `general`(① 일반회계/특별회계) · `fund`(② 기금) |
| `type` | ○ | `cut`(감액) · `increase`(증액) |
| `account` | ○ | 목록의 회계/기금명. 예: `일반회계`, `○○특별회계`, `방송통신발전기금` |
| `program`, `code` | ○ | 세부사업명, 세부사업코드(`0000-000`) |
| `change` | ○ | **요구증감액(백만원, 숫자)**. 감액은 음수(-3000 → `△3,000`), 증액은 양수 |
| `prev` | ○ | 목록의 2026년 본예산(추경). 기금은 수정계획액 |
| `proposal` | ○ | 목록·내용의 2027년도 예산안(기금은 계획안) |
| `prev_initial`, `prev_revised` | 기금 ○ | 기금 표의 2026년 당초 / 수정(2026년 7월말 기준) |
| `reasons` | ○ | 수정이유 줄 목록. `❍` 는 자동으로 붙는다 |
| `sub` | 감액만 | 내역사업명. 넣으면 사업명 칸이 `세부사업명(코드)-내역사업명` 이 된다 |
| `row_prev`, `row_proposal` | 선택 | 일반회계 내역사업 감액일 때 표에 쓸 내역사업 금액. 신규는 `"-"` |
| `sub_desc` | 선택 | 내역사업 첫 줄. `{"amount":"60억원","change":"신규","rest":"는 ~ 것임"}` → `❍ 내역사업인 ‘이름’(60억원, 신규)는 ~ 것임` 으로 쓰고, 이름은 굵게·증감은 음영으로 견본 서식을 맞춘다 |

금액은 숫자로 주면 쉼표와 △를 붙인다. 빈칸이나 `-` 를 그대로 쓰려면 문자열로 준다.

## opinions — 부대의견·정책질의 (선택)

| 키 | 뜻 |
| --- | --- |
| `kind` | `부대의견` 또는 `정책질의` |
| `summary` | 목록 칸에 들어갈 짧은 요약. 줄바꿈은 `<br>` |
| `text` | 내용 칸 문장(`❍` 자동) |

## 작성 규칙 (예결위 작성안내 기준)

- **요구증감액은 증감분만 쓴다.** 1,000백만원 사업을 300 줄이려면 `-300`(△300). 반영 후 금액(700)을 쓰지 않는다. 증액도 같다.
- **증액질의는 세부사업명만** 쓴다(`sub` 금지 — 스크립트가 막는다).
- 내역사업만 질의해도 세부사업코드는 반드시 쓴다.
- 내역사업 증감 표기: 추경이 없으면 "전년 본예산 대비 ○○억원 증/감액", 추경이 있으면 "전년 추경 대비 ~", 신규면 "신규", 증감이 없으면 "전년동". 기금은 2026년 7월말 수정계획액 대비.
- **부대의견**은 예산 증감이 없는 요구 사항으로 "○○부는 ~한다." 꼴로 쓴다.
- **정책질의**는 정부 답변만 원할 때 쓴다.
- 목록과 내용의 사업 순서는 스크립트가 맞춘다: ① 감액 → ① 증액 → ② 감액 → ② 증액 → 부대의견 → 정책질의.
- 한 문서에 부처 하나. 여러 부처면 부처마다 spec 을 따로 만들어 각각 빌드한다.
- 다부처 기금(미래대응·국유재산관리·복권·기후대응기금)은 기금 소관 부처로 낸다.
