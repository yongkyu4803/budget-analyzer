kordoc + 예산 인덱스·검색 / Windows x64 / 배포본 1.1.1

1. ZIP을 C:\kordoc-kit 같은 짧은 경로에 '모두 압축 풀기' 합니다.
2. START.cmd를 더블클릭하고 1번을 선택합니다.
3. 결과가 ok: true이면 변환·색인·검색을 사용할 준비가 됐습니다.
   상세 결과는 diagnostics\last-check.json에 저장됩니다.

받는 PC에서는 GitHub, npm, pip에 접속할 필요가 없습니다.
Node.js와 Python이 들어 있으며 관리자 권한·전역 설치·PATH 변경도 필요 없습니다.
명령 프롬프트(CMD)에서 사용할 때는 먼저 이 패키지 폴더로 이동하세요.
PowerShell에서는 명령 앞에 .\를 붙이세요. 예: .\check.cmd

빠른 사용 예 (CMD)

  convert.cmd "C:\예산자료"
  kit.cmd init --root "C:\예산자료" --config "examples\msit-2027-config.json"
  budget.cmd --root "C:\예산자료" build
  budget.cmd --root "C:\예산자료" search "GPU 임차" --limit 10
  budget.cmd --root "C:\예산자료" show "검색에서 반환한 UID" --section summary
  budget.cmd --root "C:\예산자료" verify --originals

국회 상임위원회 예산안 검토보고서 (사업설명자료와 별도 문서)

  convert.cmd "C:\검토보고서폴더"
  kit.cmd init --root "C:\검토보고서작업" --config "samples\review-config.json" --review
  review.cmd --root "C:\검토보고서작업" build
  review.cmd --root "C:\검토보고서작업" verify
  review.cmd --root "C:\검토보고서작업" search "GPU 임차" --limit 10
  review.cmd --root "C:\검토보고서작업" show 1111-111 --issue 임차

review는 .budget-index\review-config.json과 review.sqlite를 따로 씁니다.
같은 폴더에 사업설명자료 색인(budget.sqlite)도 있으면 사업 코드와 제목으로 연결해 보여 줍니다.
사업 코드는 회계가 다르면 중복되므로 제목이 맞는 사업만 연결합니다.
검증은 2027년도 과기정통부 소관 검토보고서(과학기술정보방송통신위원회, 과방위) 1건으로 했습니다.
다른 상임위 보고서도 같은 편집 관례를 따를 것으로 보고 시도할 수 있게 했지만 실물로 확인하지 못했습니다.
처음 쓸 때 build 결과의 오류·경고와 .budget-index\REVIEW_CATALOG.md를 반드시 확인하세요.
목차와 본문의 소관과·사업이 어긋나면 색인을 게시하지 않고 오류를 냅니다.
review 기능은 Windows 실기에서 실행해 보지 않았습니다. check.cmd가 가상 보고서로 시험합니다.

설정 예시는 과기정통부 2027년 정부안 8권·777개 사업에 한정됩니다.
다른 자료는 연도·부처·판본·권수·사업 수·회계를 먼저 고친 별도 JSON을 지정하세요.
파일명에는 (1권), (2권)처럼 권 번호가 있어야 합니다.
현재 인덱서는 반복 통합 목차와 '(번호) 사업명 (코드)' 구조를 지원합니다.
다른 편집 형식은 어댑터 개발·검증이 필요합니다. 일반 문서 전체에 적용되지 않습니다.

변환 결과는 문서 폴더의 markdown 하위 폴더에 저장됩니다.
기본은 본문·표만 추출하며 이미지 파일은 만들지 않습니다.
HWPX는 BinData(그림·바이너리 개체)를 제외한 임시 읽기용 사본으로 변환합니다.
본문 XML·표·서식은 유지하며, 원본 해시는 변환 보고서에 기록합니다.
이미지까지 필요하면 convert.cmd "C:\예산자료" --images 를 사용하세요.
이미지 포함 시에는 원본 전체를 읽으며 kordoc의 파일 수·크기 한도를 적용합니다.
그림이 많은 문서는 이미지 포함 변환이 한도로 실패할 수 있습니다.
원본 문서는 그대로 보존합니다. 기존 출력 폴더는 덮어쓰지 않습니다.
재변환할 때는 --output "C:\예산자료\markdown-v2"를 지정하고,
.budget-index\config.json의 markdown_glob을 markdown-v2/*.md로 바꾼 뒤 build 합니다.
이미 검증된 facts.json이 있으면 새 원문에 맞춰 재검토해야 합니다.

대용량 HWPX (실제로 읽을 부분의 압축 해제 크기가 256 MiB 초과)

  convert.cmd "C:\예산자료" --max-unzip-mb 1024

신뢰하는 대용량 문서에만 이 옵션을 명시하세요. 기본 한도는 256 MiB입니다.
이미지 없는 변환은 생략한 BinData를 크기·항목 수에 포함하지 않습니다.
메모리 사용량은 문서와 이미지 포함 여부에 따라 달라집니다.
변환 중 하나라도 실패하면 해당 묶음의 출력 폴더를 게시하지 않습니다.

스킬 사용

AI-START.txt의 프롬프트를 로컬 파일·터미널에 접근할 수 있는 코딩 에이전트에 전달하세요.
동봉된 skills\kordoc, skills\budget-index, skills\budget-search를 직접 읽어 사용할 수 있습니다.
자동 검색되는 스킬 폴더에 복사하려면 다음 중 사용하는 도구에 맞는 명령을 실행하세요.

  kit.cmd install-skills --target "%USERPROFILE%\.codex\skills"
  kit.cmd install-skills --target "%USERPROFILE%\.claude\skills"

기존 동명 스킬이 하나라도 있으면 전체 설치를 중단합니다. 기존 스킬을 덮어쓰지 않습니다.
설치 후에도 이 패키지 폴더는 유지하세요. 이동 시 각 스킬의 portable-kit.json을 수정하세요.
에이전트에 스킬이 표시되지 않으면 새 세션을 열거나 스킬 파일 경로를 직접 지정하세요.
웹 채팅만으로는 PC의 .cmd 파일을 직접 실행할 수 없습니다.
검색·변환 엔진은 로컬이며, 대화에 사용하는 GPT/Claude의 연결 방식은 별도입니다.

포함 및 제한

- kordoc 4.22.13, 필수 JavaScript 의존성, Windows x64 Node.js 24.22.0.
- Python 3.14.8 임베디드, SQLite, budget-index / budget-search 1.0.0.
- HWP/HWPX/HML/DOCX/XLS/XLSX -> Markdown. HWPX 생성도 kordoc.cmd로 사용 가능.
- PDF·OCR·이미지 OCR·PNG/PDF 렌더용 선택 엔진과 OCR 모델은 미포함.
- 테스트용 가상 HWPX 1개·가상 사업 2개. 실제 정부 자료·개인 작업자료·기존 인덱스는 미포함.
- kordoc 원본 소스 ZIP, 수정 가능한 Python 코드, 라이선스, 의존성 잠금 파일 포함.
- 이 배포본은 macOS에서 조립했습니다. Windows 실행 파일의 공식 SHA-256과 x64 형식을 확인하고,
  동일 JS/Python 코드의 변환·검색을 호스트에서 시험했습니다. Windows 실기 실행은 미확인입니다.
  check.cmd가 받는 PC에서 포함된 Windows 런타임을 실제로 실행하여 확인합니다.

KORDOC_OFFLINE=1을 실행할 때마다 적용합니다. 모델 다운로드·webhook이 차단됩니다.
운영체제의 네트워크 방화벽을 설정하는 기능은 아닙니다.
원문 표의 연도·금액·단위는 검색 결과가 아닌 show의 전체 표로 확인하세요.
금액 조건 검색은 별도 검증·구조화한 facts만 대상으로 하며 자동 완성하지 않습니다.

문제 확인

- 실행창이 바로 닫히면 CMD에서 check.cmd를 실행해 오류를 확인하세요.
- 정책상 EXE 실행이 차단된 PC라면 해당 조직의 승인된 실행 환경이 필요합니다.
- 경로가 너무 길다는 오류가 나면 C:\kordoc-kit처럼 짧은 경로에 다시 풀어보세요.
- check에서 manifest 오류가 나면 파일이 누락·변경됐는지 확인하세요.
- init은 기존 설정을 덮어쓰지 않습니다. 변경 시 설정 파일을 직접 검토하세요.
- 프로그램 파일을 수정한 배포자는 developer\BUILD.md에 따라 manifest와 ZIP을 재생성하세요.

1.1.1 (2026-11-05)

  사업설명자료 색인(budget.sqlite)과 별도 DB(review.sqlite)를 쓰며, 사업 코드와 제목으로 연결합니다.

  719개에서 멈추던 문제)
- check.cmd 결과에 kit_version과 kordoc_hwp_limits가 표시됩니다.
- 1.0.0으로 변환한 Markdown은 잘렸을 수 있습니다. 1.1.0으로 다시 변환하세요.
- budget-index·budget-search·Node.js·Python은 1.0.0과 같습니다.
- 1.0.0 사용자는 UPDATE-PROMPT.txt의 프롬프트를 코딩 에이전트에 전달해 업데이트할 수 있습니다.
