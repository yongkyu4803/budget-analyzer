이 폴더는 Windows x64용 오프라인 문서 도구 배포본이다.
START-HERE.txt와 해당 작업의 skills/*/SKILL.md를 읽는다.
실행은 동봉 .cmd를 사용한다. 의존성 설치나 네트워크 호출은 필요 없다.
문서 파싱에는 convert.cmd, 인덱스·검색에는 budget.cmd를 사용한다.
국회 상임위 검토보고서는 review.cmd로 따로 색인·검색한다(사업설명자료와 다른 문서).
사용자 자료는 workspace 또는 사용자가 지정한 폴더에서 처리한다.
samples는 가상 예제다. 실제 정부 예산으로 인용하지 않는다.
